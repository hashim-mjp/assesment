# Prompt 15 — Persist prompt history

## Context for the AI

Every prompt used in the assessment must be saved.

## Prompt (copy into Cursor)

```
Set up prompt history for this repository as required by the assignment.

Need:
- .specstory/history/  (SpecStory for Cursor/VS Code, or equivalent exports)
- docs/prompt-history.md  (human-readable index of prompts used)

If we are on Kiro (or SpecStory is not in use), add a small skill that records every prompt to a file.

Index the files already in prompts/ and instruct the team to append each new chat prompt with date, tool (Cursor / Copilot / Kiro), and a link to the saved history file.

Do not log secrets, tokens, or .env contents.
```
