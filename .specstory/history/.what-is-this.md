# SpecStory / prompt history

This folder stores saved AI chat prompts for the assessment.

## Sources

- **SpecStory** (Cursor / VS Code): install the SpecStory extension to auto-save sessions here.
- **Manual / skill fallback**: when SpecStory is not installed (or on Kiro), use `skills/record-prompt/` to append each user prompt as a Markdown file in this directory.

## Naming

Prefer: `YYYY-MM-DD_<short-slug>.md`

Example: `2026-09-22_15-prompt-history.md`

## Security

Never write secrets, tokens, API keys, passwords, certificates, or `.env` contents into history files. Redact before saving.
